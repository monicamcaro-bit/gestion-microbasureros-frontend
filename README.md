# Sistema de Gestión de Microbasureros

## 1. Descripción del proyecto

El Sistema de Gestión de Microbasureros es una aplicación web desarrollada como proyecto formativo del Servicio Nacional de Aprendizaje (SENA).

Su propósito es facilitar el registro, la consulta y el seguimiento de puntos de acumulación inadecuada de residuos sólidos, reportes ciudadanos y actividades de recolección.

## 2. Tecnologías utilizadas

- React: desarrollo de la interfaz.
- JavaScript: programación de funcionalidades.
- Vite: entorno de desarrollo y compilación.
- HTML y CSS: estructura y presentación.
- Git: control de versiones.
- GitHub: alojamiento del repositorio remoto.

## 3. Funcionalidades del sistema

- Consulta de microbasureros registrados.
- Búsqueda de microbasureros por ubicación.
- Filtro por nivel de riesgo: bajo, medio y alto.
- Registro de nuevos microbasureros mediante formularios.
- Validación de campos obligatorios.
- Consulta y registro de reportes ciudadanos.
- Seguimiento de actividades de recolección.
- Filtro de actividades según su estado.
- Interfaz adaptable a computadores y dispositivos móviles.

## 4. Requisitos de instalación

Para ejecutar el proyecto se necesita:

- Node.js y npm.
- Un navegador web actualizado.
- Un editor de código como Visual Studio Code.

## 5. Instalación y ejecución

Primero, descargar o clonar el repositorio.

Abrir la carpeta del proyecto en Visual Studio Code.

En la terminal, instalar las dependencias:

```bash
npm install
```

Iniciar el servidor de desarrollo:

```bash
npm run dev
```

Abrir en el navegador la dirección local que indique Vite.

## 6. Compilación del proyecto

Para generar la versión de producción:

```bash
npm run build
```

Para visualizarla localmente:

```bash
npm run preview
```

## 7. Alcance de la demostración

La interfaz utiliza información de demostración. Los datos registrados mediante los formularios se conservan temporalmente durante el uso de la aplicación.

## 8. Control de versiones

El proyecto utiliza Git con la siguiente estrategia de ramas:

- main: versión principal.
- develop: integración de mejoras.
- feature/documentacion: elaboración de documentación.

Los cambios se registran mediante commits con mensajes descriptivos.
